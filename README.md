# KMAP Working Group website

Source of https://kmapgroup.github.io (Jekyll, GitHub Pages).

- Content lives in `_data/` (`team_members.yml`, `alumni.yml`, `pi.yml`, `events.yml`, `publications.yml`, `research.yml`); pages in `_pages/` are templates.
- Theme: Bootstrap 5 with Korea University tokens (`_sass/_kmap_variables.scss`, `_sass/SHB_css.scss`).
- Based on the Allan Lab academic website template (MIT).
